# ListenBrainz PYbot
Python interface for ListenBrainz API

## current function(s)
This script will return the number of submitted scrobbles for the current day

## Use
- pip3 install pyperclip
- fill in config.py
- optional - edit `listenbrainz.pybot.desktop` and copt into `~/.local/share/applications/`
- optional set a cron job or keybpard shortcut to trigger the script, 
- pass the option `-n` to the script to enable desktop notifications using libnotify (Ubuntu)
- Have fun
